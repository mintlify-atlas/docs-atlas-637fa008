The typing test application is built with React, Redux, and TypeScript, featuring a modular component architecture that separates concerns between UI presentation, state management, and user interaction.

## Component structure

The application consists of six components:

- **App** - Root component that orchestrates the entire application and handles global keyboard events
- **Header** - Configuration interface for test parameters (time, theme, type)
- **Test** - Main typing test interface with word display and caret tracking
- **Result** - Test results display with WPM calculation and statistics
- **CommandPallet** - Keyboard-driven command interface for quick settings access
- **Footer** - Application footer with keyboard hints and contributor information

The App component manages the conditional rendering of Test/Result components based on timer state and handles keyboard shortcuts including Ctrl+K for the command palette and Tab for resetting the test.

## State management

All components use Redux for state management through the `react-redux` hooks:

- `useSelector` - Access Redux state
- `useDispatch` - Dispatch actions to update state

The global state is typed with TypeScript using the `State` interface from `store/reducer`.

## Common patterns

### Redux integration

Components access state and dispatch actions:

```typescript
import { useDispatch, useSelector } from "react-redux";
import { State } from "store/reducer";

const { preferences, time } = useSelector((state: State) => state);
const dispatch = useDispatch();
```

### Local storage persistence

User preferences are persisted to localStorage:

```typescript
localStorage.setItem("theme", theme);
localStorage.setItem("time", `${timeLimit}`);
localStorage.setItem("type", type);
```

### Ref management

Components use React refs for DOM manipulation and focus management:

```typescript
const activeWord = useRef<HTMLDivElement>(null);
const caretRef = useRef<HTMLSpanElement>(null);
```

## Styling

Components use a combination of:

- SCSS stylesheets imported per component
- CSS modules (CommandPallet)
- Dynamic class application based on state
