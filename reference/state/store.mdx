## Store setup

The Redux store is created using the `createStore` function from Redux, with the root reducer and Redux DevTools extension support.

```typescript
import reducer from "./reducer";
import { createStore } from "redux";

export const store = createStore(
    reducer,
    (window as any).__REDUX_DEVTOOLS_EXTENSION__ &&
        (window as any).__REDUX_DEVTOOLS_EXTENSION__()
);
```

## State interface

The complete application state is defined by the `State` interface, which combines three main slices:

```typescript
export interface State {
    preferences: {
        theme: string;
        timeLimit: number;
        type: string;
    };
    word: {
        currWord: string;
        typedWord: string;
        typedHistory: string[];
        wordList: string[];
        activeWordRef: RefObject<HTMLDivElement> | null;
        caretRef: RefObject<HTMLSpanElement> | null;
    };
    time: {
        timer: number;
        timerId: NodeJS.Timeout | null;
    };
}
```

Source: `src/store/reducer.ts:19-37`

### Preferences

Stores user preferences and test configuration:
- `theme` - Selected color theme
- `timeLimit` - Test duration in seconds
- `type` - Test type selection

### Word

Manages word tracking and typing state:
- `currWord` - Current word being typed
- `typedWord` - Characters typed for current word
- `typedHistory` - Array of completed words
- `wordList` - Full list of words for the test
- `activeWordRef` - React ref to the active word element
- `caretRef` - React ref to the caret element

### Time

Handles timer state:
- `timer` - Remaining seconds in the test
- `timerId` - Reference to the active timer interval
