Welcome to the Typing Test documentation! This is a feature-rich typing speed test application built with React, Redux, and TypeScript. Test your typing speed, track your accuracy, and customize your experience with multiple themes and word lists.

## Tech stack

This application is built with modern web technologies:

- **React 17** - UI component library
- **Redux** - State management with React-Redux
- **TypeScript** - Type-safe code
- **Sass** - Advanced styling capabilities
- **React Scripts** - Build tooling and development server
