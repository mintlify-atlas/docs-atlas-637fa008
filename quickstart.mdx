This guide will help you quickly set up and run the typing test application on your local machine.

## Prerequisites

Before you begin, ensure you have the following installed:

- **Node.js** (version 14 or higher)
- **npm** (comes with Node.js)
- **Git** for cloning the repository

## Quick setup

<Steps>
  <Step title="Clone the repository">
    Clone the typing-test repository to your local machine:
    
    ```bash
    git clone https://github.com/salmannotkhan/typing-test.git
    cd typing-test
    ```
  </Step>

  <Step title="Install dependencies">
    Install all required npm packages:
    
    ```bash
    npm install
    ```
    
    This will install React, Redux, TypeScript, Sass, and all other dependencies defined in `package.json`.
  </Step>

  <Step title="Start the development server">
    Launch the application in development mode:
    
    ```bash
    npm start
    ```
    
    The app will automatically open in your browser at `localhost:3000`.
  </Step>
</Steps>

<Note>
  The development server supports hot reloading, so any changes you make to the source code will automatically refresh in your browser.
</Note>

## Taking your first typing test

Once the application is running, you can immediately start testing your typing speed:

<Steps>
  <Step title="Choose your preferences">
    At the top of the page, you'll see three option groups:
    
    - **Time**: Select test duration (15, 30, 45, 60, or 120 seconds)
    - **Theme**: Choose your preferred color scheme
    - **Type**: Select a word list (words, sentences, numbers, etc.)
    
    ```tsx
    export const options: Options = {
        time: [15, 30, 45, 60, 120],
        theme: [
            "default",
            "mkbhd",
            "mocha",
            "coral",
            "ocean",
            "azure",
            "forest",
            "rose-milk",
            "amethyst",
            "amber",
            "terminal",
            "vscode",
            "mountain",
            "pink-sky",
            "red-season",
        ],
        type: [
            "words",
            "hard-words",
            "sentences",
            "numbers",
            "got",
            "javascript",
            "python",
        ],
    };
    ```
  </Step>

  <Step title="Start typing">
    Simply start typing! The timer begins automatically with your first keystroke. 
    
    - **Green characters**: Correctly typed
    - **Red characters**: Incorrectly typed
    - **Blinking cursor**: Current typing position
  </Step>

  <Step title="View your results">
    When the timer reaches zero, you'll see your results:
    
    - **WPM (Words Per Minute)**: Your typing speed
    - **Correct Words**: Number of words typed correctly
    - **Incorrect Words**: Number of words with mistakes
    
    Click "Restart" to take another test.
  </Step>
</Steps>

## Keyboard shortcuts

The typing test includes a command palette for quick access to features:

<CodeGroup>
```bash Command palette
Ctrl+K (or Cmd+K on Mac)
```

```bash Restart test
Tab key (during test)
```
</CodeGroup>

## Building for production

When you're ready to create a production build:

```bash
npm run build
```

This creates an optimized production build in the `build/` directory.

<Tip>
  The production build is minified, optimized, and ready for deployment to any static hosting service.
</Tip>
