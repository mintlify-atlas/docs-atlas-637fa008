## Overview

The typing test application is designed for keyboard-first interaction. All features can be accessed through keyboard shortcuts, allowing you to practice without interrupting your flow.

## Global shortcuts

These shortcuts work throughout the application:

## Typing shortcuts

These shortcuts are available during active typing tests:

### Basic typing

| Key | Action |
|-----|--------|
| **Any character** | Type the character and advance the cursor |
| **Space** | Complete the current word and move to the next word |
| **Backspace** | Delete the previous character |
| **Ctrl + Backspace** | Delete the entire current word |

### Advanced navigation

<Accordion title="Backspace behavior">
  The Backspace key has context-aware behavior:

  **Within a word:**
  - Regular Backspace: Deletes one character at a time
  - Ctrl + Backspace: Deletes the entire typed word

  **At word start:**
  - If you haven't typed anything in the current word, Backspace moves back to the previous word
  - Ctrl + Backspace clears all characters in the previous word

  ```tsx recordTest.ts
  const handleBackspace = (ctrlKey: boolean) => {
      if (!typedWord && typedHistory[currIdx] !== wordList[currIdx]) {
          // Move back to previous word
          dispatch(backtrackWord(ctrlKey));
          if (ctrlKey) {
              // Clear all characters in previous word
              currWordEl.previousElementSibling!.childNodes.forEach(
                  (char: HTMLSpanElement) => {
                      char.classList.remove("wrong", "right");
                  }
              );
          }
      } else {
          if (ctrlKey) {
              // Delete entire current word
              dispatch(setTypedWord(""));
          } else {
              // Delete one character
              const newTypedWord = typedWord.slice(0, typedWord.length - 1);
              dispatch(setTypedWord(newTypedWord));
          }
      }
  };
  ```
</Accordion>

<Accordion title="Space bar behavior">
  The Space key advances to the next word only when you've typed at least one character. Pressing Space on an empty word does nothing, preventing accidental skips.

  ```tsx recordTest.ts
  case " ":
      if (typedWord === "") return; // Prevent empty word submission
      currWordEl.classList.add(
          typedWord !== currWord ? "wrong" : "right"
      );
      dispatch(appendTypedHistory());
      break;
  ```
</Accordion>

<Warning>
  Ctrl (Control) key is used for advanced shortcuts. On macOS, use Cmd (Command) instead of Ctrl where applicable.
</Warning>

## Command palette

The command palette (Ctrl + K) provides keyboard-driven access to all application settings.

### Using the command palette

<Steps>
  <Step title="Open the palette">
    Press **Ctrl + K** to open the command palette. A search interface appears overlaying the typing area.
  </Step>

  <Step title="Select a category">
    Type to filter options or use arrow keys to navigate:
    - **time** - Set test duration
    - **theme** - Change color theme
    - **type** - Select wordlist

    Press **Enter** to select a category.
  </Step>

  <Step title="Choose a value">
    After selecting a category, available options appear. Navigate with arrow keys and press **Enter** to apply.
  </Step>

  <Step title="Close the palette">
    Press **Escape** to close without making changes, or the palette auto-closes after applying a setting.
  </Step>
</Steps>

### Command palette shortcuts

While the command palette is open:

| Key | Action |
|-----|--------|
| **Arrow Up** | Move selection up in the list |
| **Arrow Down** | Move selection down in the list |
| **Enter** | Select the highlighted option |
| **Escape** | Close the command palette |
| **Any text** | Filter options by typing |

### Command palette implementation

The command palette uses a two-stage selection process:

```tsx CommandPallet.tsx
const handlePalletKeys = (e: KeyboardEvent) => {
    if (e.key === "ArrowUp") {
        setHighlightedOption((op) => (op > 0 ? op - 1 : op));
    } else if (e.key === "ArrowDown") {
        setHighlightedOption((op) =>
            op < commandList.length - 1 ? op + 1 : op
        );
    } else if (e.key === "Enter") {
        const command = commandList[highlightedOption];
        handleCommandSelection(command);
    } else if (e.key === "Escape") {
        props.setShowPallet(false);
    }
    e.stopPropagation();
};
```

## Accessibility features

The keyboard shortcuts support accessibility:

- **Full keyboard navigation** - No mouse required for any feature
- **Visual feedback** - Selected options are highlighted with theme colors
- **Smooth scrolling** - Active words automatically scroll into view
- **Caret animation** - Blinking caret provides clear position feedback

<Note>
  All shortcuts are designed to work with standard keyboard layouts. If you use a non-QWERTY layout, the shortcuts remain in the same physical positions.
</Note>
