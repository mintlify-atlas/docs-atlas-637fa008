The typing test includes 15 built-in themes that customize the background, text, highlight, and foreground colors. All themes are defined in `themes.scss` using CSS custom properties.

## Theme structure

Each theme defines four CSS variables:

- `--bg-color` - Main background color
- `--font-color` - Primary text color
- `--hl-color` - Highlight/accent color (used for active elements)
- `--fg-color` - Foreground color (used for secondary elements)

## How themes are applied

Themes are implemented using CSS custom properties (variables) in `themes.scss`. When you select a theme:

1. The theme name is stored in Redux state (`reducer.ts:138-139`)
2. The corresponding CSS class is applied to the root element
3. All components automatically inherit the color scheme through CSS variables

<Tabs>
  <Tab title="CSS Structure">
    ```scss
    .default {
        --bg-color: black;
        --font-color: lightslategray;
        --hl-color: orange;
        --fg-color: #292f34;
    }
    ```
    
    Each theme is a CSS class that defines the four color variables.
  </Tab>
  
  <Tab title="Redux State">
    ```typescript
    preferences: {
        theme: string;
        timeLimit: number;
        type: string;
    }
    ```
    
    The selected theme name is stored in the preferences slice of Redux state.
  </Tab>
  
  <Tab title="Component Usage">
    Components reference the CSS variables directly:
    
    ```css
    background-color: var(--bg-color);
    color: var(--font-color);
    ```
  </Tab>
</Tabs>

## Switching themes

You can change themes at any time using the command palette (keyboard shortcuts) without interrupting your test. The new theme applies immediately across all components.

<Note>
Theme preferences persist in local storage, so your selected theme will be remembered when you return to the app.
</Note>

## Creating custom themes

To add a new theme, define a new CSS class in `themes.scss` with the four required color variables:

```scss
.my-custom-theme {
    --bg-color: #yourcolor;
    --font-color: #yourcolor;
    --hl-color: #yourcolor;
    --fg-color: #yourcolor;
}
```

<Warning>
Make sure there is sufficient contrast between `--bg-color` and `--font-color` for readability during typing tests.
</Warning>
