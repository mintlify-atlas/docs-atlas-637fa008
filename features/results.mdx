After the timer reaches zero, the typing test displays your results including words per minute (WPM) and accuracy statistics. All calculations are performed in `Result.tsx`.

## WPM calculation

Words Per Minute (WPM) is the standard metric for typing speed. This application uses the industry-standard formula that counts 5 characters as one "word."

### The formula

```typescript
const wpm = ((correctChars + spaces) * 60) / timeLimit / 5;
```

Breaking down the calculation (`Result.tsx:19`):

<Steps>
  <Step title="Count correct characters">
    Sum the length of all correctly typed words:
    
    ```typescript
    let correctChars = 0;
    result.forEach((r, idx) => {
        if (r) correctChars += wordList[idx].length;
    });
    ```
  </Step>
  
  <Step title="Add spaces">
    Count the number of words typed (each word requires a space):
    
    ```typescript
    const spaces = wordList.indexOf(currWord);
    ```
  </Step>
  
  <Step title="Calculate rate per minute">
    Multiply by 60 to convert from the time limit to a per-minute rate:
    
    ```typescript
    (correctChars + spaces) * 60 / timeLimit
    ```
  </Step>
  
  <Step title="Divide by 5">
    Divide by 5 to convert characters to "words" (industry standard):
    
    ```typescript
    / 5
    ```
  </Step>
</Steps>

<Info>
The division by 5 is an industry standard. This means typing "hello" (5 characters) + space counts as 1.2 words for WPM calculation.
</Info>

## Accuracy metrics

The results screen displays both correct and incorrect word counts.

### Word comparison

Each typed word is compared exactly against the target word:

```typescript
const result = typedHistory.map(
    (typedWord, idx) => typedWord === wordList[idx]
);
```

This creates a boolean array where `true` means the word was typed correctly and `false` means it had any errors.

<Warning>
A word is only counted as correct if it matches exactly - any typos, extra characters, or missing characters mark the entire word as incorrect.
</Warning>

### Correct words

```typescript
result.filter((x) => x).length
```

Counts how many words in the `result` array are `true` (perfect matches).

### Incorrect words

```typescript
result.filter((x) => !x).length
```

Counts how many words in the `result` array are `false` (had errors).

## Understanding your results

### Only correct characters count

The WPM formula only includes characters from correctly typed words:

```typescript
result.forEach((r, idx) => {
    if (r) correctChars += wordList[idx].length;
});
```

If you typed a word incorrectly, those characters don't contribute to your WPM at all.

<Tabs>
  <Tab title="Scenario A">
    You typed 10 words, all correct:
    - Correct words: 10
    - Incorrect words: 0
    - All characters count toward WPM
  </Tab>
  
  <Tab title="Scenario B">
    You typed 10 words, 8 correct, 2 wrong:
    - Correct words: 8
    - Incorrect words: 2
    - Only characters from the 8 correct words count toward WPM
  </Tab>
  
  <Tab title="Scenario C">
    You typed 10 words, all incorrect:
    - Correct words: 0
    - Incorrect words: 10
    - 0 WPM (no correct characters)
  </Tab>
</Tabs>

### Spaces are counted

Each word you complete adds both its characters AND a space to the calculation:

```typescript
const spaces = wordList.indexOf(currWord);
const wpm = ((correctChars + spaces) * 60) / timeLimit / 5;
```

The `spaces` variable equals the number of words completed (since each word is followed by a space).

<Note>
This is why the formula includes `+ spaces` - it accounts for the space character between words that you typed.
</Note>

### Time limits affect WPM scaling

Shorter time limits can lead to higher WPM scores because:

- Less time for fatigue to set in
- Easier to maintain peak speed for 15 seconds vs 60 seconds
- The `* 60 / timeLimit` factor scales shorter tests up to a per-minute rate

<Info>
For fair comparisons, always compare WPM scores from the same time limit. A 60-second test is the most standard benchmark.
</Info>

## Restart button

After viewing results, click the Restart button to reset the test:

```typescript
<button onClick={() => resetTest()}>Restart</button>
```

This will:
1. Clear all typed history
2. Reset the timer to the configured time limit
3. Shuffle the wordlist again for a fresh test
4. Return to the typing test screen
